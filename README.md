# GoCorona

Статичная адаптивная лендинг-страница о сервисе здравоохранения GoCorona.

## Features

- Информационные секции о здоровье, поддержке и мобильном приложении
- Адаптивная вёрстка и локальные графические ресурсы

## Technologies

- HTML
- CSS
- Google Fonts

## Getting Started

Откройте `index.html` в браузере. Сборка и переменные окружения не требуются.
